WHH-DB GitHub Pages update

1. Extract this ZIP.
2. Open https://github.com/Mekdes9708/WHH-DB
3. On main, choose Add file > Upload files.
4. Upload the extracted files and folders into the repository root, replacing index.html. Do not upload the ZIP itself or an extra enclosing folder.
5. Commit the changes. GitHub Pages will rebuild automatically.
6. Open https://mekdes9708.github.io/WHH-DB/ and refresh.
